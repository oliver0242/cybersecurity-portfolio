# TryHackMe: DNS in Detail

## Project Overview
This project documents my learning about the Domain Name System (DNS) through a hands-on TryHackMe training room.

## Objective
Understand how DNS translates domain names into information that computers use to communicate across networks.

## Lab Environment
- Platform: TryHackMe
- Room: DNS in Detail
- Activity: Guided cybersecurity training

## Key Concepts
- DNS resolution and domain hierarchy
- A and AAAA records
- CNAME records
- MX records
- TXT and NS records
- Recursive and authoritative DNS servers
- DNS caching and Time to Live (TTL)

## Security Relevance
DNS knowledge helps security analysts investigate suspicious domains, understand network activity, and troubleshoot name-resolution problems.

## Defensive Lessons
- Review DNS logs during security investigations.
- Look for unusual domain requests.
- Understand normal DNS behavior.
- Apply appropriate DNS monitoring and security controls.

## What I Learned
This lab helped strengthen my understanding of DNS fundamentals and the importance of name resolution in networking and cybersecurity.
