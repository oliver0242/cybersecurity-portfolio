# TryHackMe: HTTP in Detail

## Project Overview
This report documents my learning about HTTP, the protocol used by web browsers and servers to exchange information.

## Objective
Understand how HTTP requests and responses work and why these concepts matter in web application security.

## Lab Environment
- Platform: TryHackMe
- Room: HTTP in Detail
- Activity: Guided cybersecurity training

## Key Concepts
- HTTP requests and responses
- HTTP methods, including GET and POST
- HTTP status codes
- Request headers and response headers
- Cookies and sessions
- HTTPS and encrypted communication

## Security Relevance
Understanding HTTP helps security practitioners analyze web traffic, troubleshoot application behavior, and recognize potentially suspicious requests or responses.

## Defensive Lessons
- Use HTTPS to protect data in transit.
- Handle session cookies securely.
- Validate user input on the server.
- Review HTTP logs for unusual activity.
- Use appropriate security headers.

## What I Learned
This lab strengthened my understanding of web communication and the HTTP concepts that underpin web application security.
