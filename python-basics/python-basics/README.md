# Python Basics: Password Strength Checker

## Objective
Build a beginner Python program that evaluates basic password characteristics.

## Skills Demonstrated
- Python functions
- Conditional statements
- Loops and character checks
- String handling
- Basic security awareness

## How It Works
The program checks password length and whether it contains lowercase letters, uppercase letters, digits, and punctuation. It returns a simple estimated strength category.

## Limitations
This is an educational demonstration, not a complete password-security assessment. It does not check breached-password databases, predictability, or resistance to modern password-cracking methods.

## Security Note
Use only made-up test passwords. Never enter real passwords into public demonstrations or publish passwords in source code.
